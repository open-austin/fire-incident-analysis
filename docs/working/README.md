# docs/working — process & review material

Working documents that support the project but are **not part of the final product**: review handouts, feedback triage, session handoffs, discussion guides. Kept here so the top-level `docs/` holds only finished deliverables (the reports, the policy brief, the data dictionary, and `METHODS.md`).


## Structure

One subfolder per review round or work thread:

```
docs/working/
  <thread>/
    handout.*    — give-out / discussion material for that round
    handoff.*    — session handoff notes (where we picked up / left off)
    ...
```

## Contents

| Folder | Thread | Key files |
|---|---|---|
| `pr13/` | PR #13 review (Issue #14 feedback) | `handout.md` / `handout.html` (decision guide, 4 open questions), `handoff.md` (session handoff) |
